# COBU ERP

Aplicação de ponto de venda para Costa's Burgers, instalável como PWA e utilizável offline depois do primeiro carregamento.

- **Abrir a aplicação:** https://oldzaby.github.io/cobupos/
- **Instruções de utilização:** [LEIA-ME.md](LEIA-ME.md)

Os dados ficam no armazenamento local e podem sincronizar pela internet através do Supabase, com autenticação do dono, alteração e recuperação da palavra-passe e políticas RLS; cada pessoa continua a usar o PIN COBU local. Para sincronizar apenas na rede local, usa o executável Windows distribuído separadamente.
